10. 作る側に回る

VRChat のアバターやワールドの多くは、利用者自身が作っている。本章では、制作に興味を持った人に向けて、制作の全体像を紹介する。具体的な操作手順は扱わない。実際に作業するときは、付録 C: 参考文献・リンク集 に挙げた公式ドキュメントを参照してほしい。

10.1. 制作の全体像

アバターやワールドを VRChat で使うには、次の 3 つのソフトウェアを使う。

表 10.1 制作に使うソフトウェア

ソフトウェア

役割

Unity

ゲームなどの制作に広く使われている開発環境。アバターやワールドの組み立て、設定を行う。VRChat が指定するバージョンを使う必要がある。

VRChat Creator Companion

VRChat 向けの制作プロジェクトを作成・管理するツール。必要な SDK などを自動で用意する。

VRChat SDK

Unity に組み込んで使う、VRChat 用の部品と機能のまとまり。アバターやワールドを VRChat 用に設定し、アップロードする。

制作の流れを 図 10.1 に示す。

アップロードするには、安全・マナー・トラブル対策 で説明した Trust Rank が New User 以上である必要がある。また、PC 向けと、単体型 VR やスマートフォン向けのデータは、それぞれ別にアップロードする。

10.2. アバター制作の概要

アバター制作といっても、3D モデルを一から作るとは限らない。初心者が最初に取り組むことが多いのは、次のような作業である。

  • 販売サイトで購入したアバターを、自分のアカウントにアップロードする。

  • 購入したアバターに、衣装や髪型を着せ替える（改変）。

  • VRoid Studio などのツールで作ったモデルを、VRChat 用に設定してアップロードする。

VRChat のアバターには、見た目のほかに次のような設定を組み込める。

  • ハンドジェスチャーと表情の対応

  • メニューから切り替えられる衣装や小物

  • 髪や服、しっぽなどの揺れ（PhysBones）

  • ほかのアバターに触れたときの反応

慣れてきたら、Blender などの 3D モデル制作ソフトウェアでアバターや衣装を一から作ることもできる。

10.3. ワールド制作の概要

ワールドは、Unity で空間を組み立てて作る。地形や建物、家具などを配置し、光の当たり方を設定して雰囲気を作る。3D の素材は、自分で作るほか、Unity の素材ストアなどで入手できる。

ワールドに動きのある仕掛けを組み込むには、Udon という仕組みを使う。Udon を使うと、ボタンを押すと扉が開く、動画を再生する、参加者どうしでゲームを遊ぶといった仕掛けを作れる。Udon の処理は、部品を線でつないで組み立てる方法（Udon Graph）で作れるほか、C# というプログラミング言語で書くこともできる（UdonSharp）。

アップロードしたワールドは、最初は自分だけが入れる非公開の状態である。Trust Rank が User 以上になると、ほかの利用者にも公開できる。公開されたワールドは、まず試験的な区分（Community Labs）に置かれ、訪問者の反応などにもとづいて一般の一覧に掲載される。

10.4. 配布・販売と権利

作ったアバターやワールド、衣装などは、ほかの利用者に配布・販売することもできる。BOOTH などの外部の販売サイトで販売するほか、条件を満たせば公式のアバターマーケットプレイスで販売することもできる。

制作や配布では、権利の扱いに注意する。

  • 素材を使うときは、その素材の利用規約を確認する。改変や再配布、商用利用が許可されているかは素材ごとに異なる。

  • 自分の制作物を配布・販売するときは、利用規約を定めて明示する。

  • 他人が作ったアバターやワールドのデータを無断で使ったり、アップロードしたりしてはならない。

  • 既存のアニメやゲームのキャラクターなど、他人の著作物を無断でアバターにして配布・販売してはならない。

10.5. 次に読むべき資料

制作を始めるときは、まず VRChat の公式の制作者向けドキュメント（Creator Docs）を読むとよい。Unity や Creator Companion の導入から、アバターやワールドの設定、Udon の使い方まで、公式の手順がまとまっている。日本語の解説記事や書籍も多いが、VRChat の制作環境は頻繁に更新されるため、情報の新しさに注意する。

参考になる資料は 付録 C: 参考文献・リンク集 にまとめている。
