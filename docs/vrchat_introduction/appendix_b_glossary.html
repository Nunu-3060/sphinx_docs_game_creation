付録 B: 用語集

本書に登場する主な用語を、英字、五十音の順に並べる。

Community Labs

新しく公開されたワールドが、最初に置かれる試験的な区分。訪問者の反応などにもとづいて、一般の一覧に掲載される。

GPU

画像の処理を担うパソコンの部品。グラフィックボードに搭載されている。VRChat の快適さを大きく左右する。

HMD

Head Mounted Display（ヘッドマウントディスプレイ）の略。頭に装着して使う表示装置で、VR 機器の本体を指す。

Main Menu

目の前に大きく表示されるメニュー。ワールドの検索、アバターの変更、設定などを行う。

OSC

Open Sound Control の略。VRChat と外部のプログラムがデータをやり取りするための通信の仕組み。

PC VR

高性能な Windows パソコンに VR 機器をつないで遊ぶ方法。

PhysBones

アバターの髪や服、しっぽなどの揺れを表現する VRChat の仕組み。

Quick Menu

手元に表示される小さなメニュー。マイクのミュートやカメラなど、よく使う機能をまとめている。

Safe Mode

緊急時に、ほかの利用者のアバターや音をまとめて表示しないようにする機能。

Safety システム

ほかの利用者のアバターや声などのうち、何を自分に見せ、聞かせるかを Trust Rank ごとに制御する仕組み。

SDK

Software Development Kit の略。ソフトウェアの開発に必要な部品や機能のまとまり。VRChat SDK は、アバターやワールドを VRChat 用に設定し、アップロードするために使う。

Trust Rank

VRChat での活動実績にもとづく、利用者の信頼度の段階。Visitor、New User、User、Known User、Trusted User の順に上がる。

Udon

ワールドに動きのある仕掛けを組み込むための VRChat の仕組み。

UdonSharp

Udon の処理を、プログラミング言語 C# で書くための仕組み。

Unity

ゲームなどの制作に広く使われている開発環境。VRChat のアバターやワールドの制作に使う。

VR

Virtual Reality（仮想現実）の略。コンピューターが作った空間の中にいるような感覚を得る技術。

VR 酔い

VR の映像と体の感覚の食い違いによって起こる、乗り物酔いに似た症状。

VRChat Creator Companion

VRChat 向けの制作プロジェクトを作成・管理するツール。必要な SDK などを自動で用意する。

VRChat Credits

VRChat の中で使う通貨。アバターマーケットプレイスでの購入などに使う。

VRChat+

VRChat の運営を支援する、月額または年額の有料の会員制度。

アバター

VRChat の中で利用者がまとう姿。

アバターマーケットプレイス

VRChat の中でアバターを試着し、購入できる公式の仕組み。

インスタンス

ひとつのワールドから作られる、個別の部屋。インスタンスの種類によって、入れる人の範囲が決まる。

改変

購入したアバターに衣装や髪型を着せ替えるなど、手を加えて自分好みにすること。日本の利用者の間で使われる言葉。

グループ

共通の趣味や活動でまとまったコミュニティを、VRChat の中で運営するための機能。

集会

決まった日時に、特定の趣味や属性を持つ人が集まって話す定期イベント。日本の利用者の間で使われる言葉。

スナップターン

一定の角度ずつ瞬時に向きを変える回転方式。VR 酔いを起こしにくい。

ソーシャル VR

VR の技術を使い、離れた場所にいる人どうしが同じ仮想空間に集まって交流するサービス。

単体型 VR

パソコンなしで動く VR 機器だけで遊ぶ方法。または、そのような VR 機器。

チャットボックス

頭の上に短い文字を表示して、文字でやり取りするための機能。

デスクトップモード

VR 機器を使わず、パソコンの画面とキーボード、マウスで遊ぶ方法。

トラッカー

体に着けて、その部位の位置や向きを測るための機器。フルボディトラッキングに使う。

トラッキング

体の部位の位置や向きを測り、アバターの動きに反映する技術。

パフォーマンスランク

アバターの処理の重さを示す 5 段階の評価。Excellent、Good、Medium、Poor、Very Poor の順に重くなる。

パブリックアバター

作者が誰でも使えるように公開しているアバター。無料で使える。

表示名

VRChat の中で、ほかの利用者に見える名前。

フルボディトラッキング

頭と両手に加えて、腰や足などの位置も測り、全身の動きをアバターに反映すること。

フレンド

お互いに承認しあった利用者どうしの関係。相手がオンラインかどうかや、どこにいるかが分かるようになる。

ポータル

ワールドの中に置かれた、別のワールドへの入口。

ホームワールド

VRChat にログインしたときに最初に入るワールド。

ワールド

VRChat の仮想空間。利用者が作成して公開している。
