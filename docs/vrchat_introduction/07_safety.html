7. 安全・マナー・トラブル対策

VRChat は、世界中の多様な人が集まる場である。多くの利用者は親切だが、ときにはトラブルに出会うこともある。本章では、自分の身を守るための仕組みと、気持ちよく過ごすためのマナーを説明する。

7.1. Trust Rank の仕組み

Trust Rank は、利用者の VRChat での活動実績にもとづく信頼度の段階である。VRChat で過ごした時間やほかの利用者との交流などをもとに、自動的に上がっていく。具体的な条件は公開されていない。Trust Rank の段階を 図 7.1 に示す。

表 7.1 Trust Rank の段階

段階

説明

Visitor

アカウントを作ったばかりの段階

New User

少し活動した段階。アバターやワールドのアップロードができるようになる。

User

一定の活動実績がある段階。多くの機能が使えるようになる。

Known User

長く活動している段階

Trusted User

長く活動し、信頼が積み重なった段階

Trust Rank は、表示名やプロフィールの色で示される。Trust Rank は活動の目安であり、その人の人柄を保証するものではない。逆に、ランクが低い人が悪い人というわけでもない。始めたばかりの人は誰でも Visitor から始まる。

なお、ランクを上げることを目的に不自然な行動をとる必要はない。普段どおりに過ごしていれば、時間とともに上がっていく。

7.2. Safety システム

Safety システムは、ほかの利用者のアバターや声などのうち、何を自分に見せ、聞かせるかを制御する仕組みである。Trust Rank ごとに、次のような項目の表示を許可するかどうかを設定できる。

  • 声

  • アバターの見た目

  • アバターが出す音

  • アバターの動きや、光・粒子などの効果

設定は、シールドの強さとして「最大」「標準」「なし」などの段階から選べるほか、項目ごとに細かく決めることもできる。始めたばかりのうちは、標準の設定のままでよい。たとえば、まぶしい光を出すアバターや大きな音を出すアバターに困ったときは、設定を強めることを検討する。

また、緊急時には、所定のボタン操作でほかの利用者のアバターや音をまとめて表示しないようにできる（Safe Mode）。大きな音や激しい光で気分が悪くなったときなどに使う。操作方法は機器によって異なるため、公式ドキュメントで確認しておくとよい。

個々の利用者に対しては、アバターの表示を個別に切り替えることもできる。

7.3. ブロック・ミュート・通報

ほかの利用者から不快な思いをさせられたときは、次の手段を使える。いずれも Quick Menu で相手を選んで操作する。

表 7.2 トラブルに対処する手段

手段

効果

使う場面

ミュート

相手の声が自分に聞こえなくなる。

声が大きい、話しかけ方が不快など

アバターを非表示

相手のアバターが簡略化された姿で表示される。

アバターの見た目や効果が不快など

通報

ブロックやミュートは、相手に通知されない。不快に感じたら、ためらわずに使ってよい。その場を離れて別のインスタンスに移るのも有効な手段である。

7.4. 個人情報とプライバシー

VRChat では、アバターの姿で交流するため、相手が現実にどんな人かは分からない。親しくなった相手であっても、個人情報の扱いには注意が必要である。

  • 本名、住所、勤務先や学校、電話番号などは教えない。

  • 表示名やプロフィールに、個人を特定できる情報を書かない。

  • 写真や声の背景に、個人を特定できる情報（窓の外の景色、家族の声など）が含まれないように気をつける。

  • VRChat の外の連絡先（SNS やメッセージアプリ）を交換するときは、慎重に判断する。

  • 金銭のやり取りや、外部サイトへの誘導には応じない。

未成年の利用者は、とくに注意が必要である。知り合った人から個人的な連絡や写真を求められたときは、応じずに保護者などの信頼できる大人に相談してほしい。成年の利用者も、未成年の利用者とは適切な距離を保つことが求められる。

7.5. よくあるマナー

VRChat には、利用者の間で共有されているマナーがある。主なものを次に挙げる。

距離感

初対面の相手に、急に顔を近づけたり体に触れたりしない。仮想空間であっても、近づかれることに抵抗を感じる人は多い。現実で初対面の人と接するときと同じ距離感を心がける。

声量

大声を出したり、マイクに雑音を入れたりしない。周囲の音が入りやすい環境では、話すとき以外はマイクをミュートにする。

場の雰囲気

静かに過ごす場所、イベント会場など、場によって雰囲気は異なる。入ったらまず周りの様子を見て、その場に合わせて振る舞う。

撮影

写真を撮るとき、公開するときは、写る人の許可を得る（基本的な遊び方 を参照）。

初心者への接し方

慣れてきたら、困っている初心者に声をかけて手助けするとよい。多くの利用者も、始めたばかりのころは誰かに助けられている。

7.6. 利用規約とコミュニティガイドラインの要点

VRChat の利用には、利用規約とコミュニティガイドラインが適用される。違反すると、アカウントの一時停止や利用停止などの処分を受けることがある。主な禁止事項は次のとおりである。

  • 嫌がらせ、差別、脅迫などの迷惑行為

  • 性的な内容や暴力的な内容を、それを望まない人の目に触れる場所で見せること

  • 他人のなりすまし

  • 他人が作ったアバターやワールドのデータを無断で抜き出したり、使ったりすること

  • 不正なツールを使った妨害や、VRChat の仕組みへの攻撃

  • 未成年者を対象とした不適切な行為

ここに挙げたのは要点のみである。正確な内容は、付録 C: 参考文献・リンク集 に挙げた公式の利用規約とコミュニティガイドラインで確認してほしい。

7.7. 健康面の注意

VRChat は、気づかないうちに長時間遊んでしまうことがある。健康のために、次の点に気をつける。

長時間の利用

VR 機器を長時間着け続けると、目の疲れ、首や肩のこり、肌のかぶれなどが起こりやすい。1 時間に 1 回程度は VR 機器を外して休憩し、水分をとる。

睡眠

深夜まで遊んで睡眠時間が削られると、生活に影響が出る。終わる時間を決めておくとよい。なお、VRChat には VR 機器を着けたまま眠る文化もあるが、機器の重さや熱、衛生面への影響があるため、勧めない。

周囲の安全

VR 機器を着けている間は、周囲が見えない。家具や壁にぶつからないよう、遊ぶ場所を片づけておく。多くの VR 機器には、遊ぶ範囲の境界を設定し、境界に近づくと警告する機能があるので、必ず設定する。小さな子どもやペットがいる場合は、とくに注意する。

体調の変化

VR 酔いや目の疲れなど、体調が悪くなったときはすぐにやめる（はじめてのログイン を参照）。
