1. はじめに

1.1. 本書の目的と対象読者

本書は、ゲームを作るときに必要になる数学と物理を、実際に動くコードとともに学ぶための入門書である。対象読者は次のような人を想定している。

  • Python で簡単なプログラムを書けるが、ゲームを作った経験は無いエンジニア

  • 工学系の大学生で、高校数学（三角関数、ベクトル、微分・積分の初歩）を一度は学んだ人

数学や物理の教科書は、定義と定理を順に積み上げていく。一方、ゲームを作るときは「敵をプレイヤーの方へ向けたい」「ジャンプの手触りを良くしたい」「弾が壁をすり抜けてしまう」といった具体的な困りごとが先にあり、それを解く道具として数学や物理が必要になる。本書は後者の順序で書いている。各章は、おおむね次の流れで進む。

  1. ゲームで起きる困りごと

  2. それを解く数学・物理の道具

  3. Python での実装

  4. 図や動くデモでの確認

本書を読み終えると、次のことができるようになる。

  • キャラクターの移動・追尾・向きの変更を、ベクトルと三角関数で書ける。

  • フレームレートに依存しない移動・ジャンプ・落下を書ける。

  • 円・長方形・多角形などの衝突判定と、押し戻し・反射などの応答を書ける。

  • 補間・イージング・乱数を使って、動きに手触りを付けられる。

  • 物理エンジンが内部で何をしているかを大まかに説明でき、自作と既存のエンジンを使い分けられる。

1.3. 「本物の物理」と「気持ちよい物理」

ゲームの物理は、現実の物理を正確に再現することが目的ではない。たとえば、アクションゲームのキャラクターの多くは、現実の人間には不可能なほど高く跳び、空中で向きを変え、着地の瞬間にぴたりと止まる。それでも遊ぶ人は不自然に感じず、むしろ思いどおりに動くことを心地よく感じる。

そのため本書では、物理法則をそのまま使う方法と、遊びやすさのために法則をあえて崩す方法の両方を扱う。第 10 章では、まず放物運動の式から重力と初速を決め、その後で「下降中だけ重力を強める」「足場から落ちた直後でもジャンプを受け付ける」といった、現実には無い調整を加える。こうした調整を意図的に行えるのは、元になる物理を理解しているからである。

1.4. 本書の構成と読み方

図 1.1 に章の関係を示す。第 2 章から第 9 章までが数学、第 10 章から第 14 章までが物理、第 15 章がまとめの演習である。

前から順に読むことを想定しているが、第 7 章（3D の回転）は 2D のゲームだけを作るなら後回しにしてよい。数式は導出を細かく追うより、図とコードで意味をつかむことを優先している。厳密な証明に興味がある場合は、付録 C 参考文献に挙げた文献を参照してほしい。

本書の数式で使う記号は付録 A 数式・記号の早見表に、用語は付録 B 用語集にまとめている。

1.4.1. 本書で使う座標系

数学の教科書では y 軸を上向きに取るが、ゲームの画面では y 軸を下向きに取ることが多い（座標系と数値で説明する）。本書のサンプルコードはすべて画面座標（y 軸が下向き）で書いている。数式や図は、特に断らない限り、どちらの座標系でも成り立つように書いている。向きによって意味が変わる箇所（回転の向き、外積の符号）では、そのつど注意を書いている。

1.5. 実行環境の準備

サンプルコードは Python 3.12 以上で動作する。次のライブラリーを使う。

表 1.2 使用するライブラリー

ライブラリー

用途

pygame-ce

ウィンドウの表示、描画、キーボードとマウスの入力。ベクトルのクラス pygame.Vector2 も使う

pymunk

2D の物理エンジン（第 14 章で使う）

次のコマンドでインストールできる。

リスト 1.1 ライブラリーのインストール
1py -m pip install pygame-ce pymunk

サンプルコードは付録 D サンプルコード一覧からダウンロードできる。ダウンロードしたフォルダーで、次のように実行する。

リスト 1.2 サンプルコードの実行
1py vectors_demo.py

いくつかのサンプルコードは、同じフォルダーにある別のファイル（collision.py など）を import して使う。ファイルはすべて同じフォルダーに置いてほしい。デモの画面に表示する文字は、フォントの用意が要らないように英語にしている。

注釈

pygame-ce は、pygame から分かれて開発が続けられているライブラリーである。import するときの名前は pygame と同じで、import pygame と書く。元の pygame が入っていると衝突するので、両方を同時にインストールしないこと。
