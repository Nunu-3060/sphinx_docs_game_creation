コードの検査

サンプルコードは、PEP 8 に従って書き、すべての関数に型ヒントを付けている。examples フォルダーで次のコマンドを実行すると、flake8（コードの書き方の検査、行長は 120 文字まで許容）と mypy（型の検査、strict = True）で検査できる。

1python -m pip install flake8 mypy
2python -m flake8
3python -m mypy .

設定は setup.cfg に書いてある。

リスト 1 setup.cfg
 1# Settings for checking the sample code.
 2# Run the following commands in this directory (examples):
 3#   python -m flake8
 4#   python -m mypy .
 5# The figure scripts in ../source/_scripts are checked with the same settings:
 6#   python -m flake8 --config setup.cfg ../source/_scripts
 7#   python -m mypy --config-file setup.cfg ../source/_scripts
 8# Keep this file ASCII only: mypy reads it with the locale encoding
 9# (cp932 on Japanese Windows), so non-ASCII characters break it.
10
11[flake8]
12max-line-length = 120
13exclude = .mypy_cache,__pycache__,build,dist
14
15[mypy]
16strict = True
