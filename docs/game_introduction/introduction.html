はじめに

本書の目的

ゲームは、誰もが一度は遊んだことのある身近なものである。しかし「ゲームとは何か」「なぜ面白いのか」と聞かれて、筋道を立てて答えられる人は多くない。本書は、この問いに次の 3 段階で答えることを目的とする。

表 1 本書の構成

部

内容

問い

第 1 部　ゲームを知る

定義、歴史、種類

ゲームとは何か。どこから来て、どのような種類があるか

第 2 部　ゲームの仕組み

制作、数理、デザイン

ゲームはどう作られ、何が面白さを生むのか

第 3 部　ゲームを遊ぶ

遊び方、分析的に遊ぶ、社会

実際に遊んで、学んだことを確かめる

本書の中心は第 3 部である。第 1 部と第 2 部は、第 3 部でゲームを選び、遊び、分析するための道具をそろえる役割を持つ。1〜8 章の終わりには、遊んで確かめる短い演習を置いた。

対象読者

本書は次のような読者を想定する。

  • Python などのプログラミングの経験があるエンジニア、または工学系の大学生

  • ゲーム制作の経験は無い、または浅い

  • アナログゲームとデジタルゲームの両方を楽しむ

ゲーム制作の知識は前提としない。数理の章（5 章）では高校程度の確率と、二進数の排他的論理和を使う。

読み方

最初から順に読むことを想定しているが、早く第 3 部に進みたい場合は、1 章　ゲームとは何か → 6 章　デザイン → 7 章　遊び方・楽しみ方 → 8 章　分析的に遊ぶ の順に読み、必要に応じて他の章に戻ってもよい。

本書では、テレビゲーム、ビデオゲーム、コンピューターゲームなどと呼ばれるものをまとめてデジタルゲームと呼ぶ。また、ボードゲーム、カードゲーム、TRPG など、コンピューターを必要としないゲームをまとめてアナログゲームと呼ぶ。商用の作品は名前と説明だけで取り上げ、図はすべて本書のために作成した。
