付録 B　ショートカットキー一覧

Godot 4.7.2 のエディターの既定のショートカットキーのうち、よく使うものをまとめる。ショートカットキーは「エディター」→「エディター設定」の「ショートカット」タブで確認・変更できる。

全般

表 80 全般のショートカットキー

キー

操作

F5

プロジェクトを実行

F6

現在のシーンを実行

Ctrl + Shift + F5

特定のシーンを実行

F7

実行中のプロジェクトを一時停止

F8

プロジェクトの実行を停止

Ctrl + N

新規シーン

Ctrl + O

シーンを開く

Ctrl + S

シーンを保存

Ctrl + Z

元に戻す

Ctrl + Y、Ctrl + Shift + Z

やり直す

Ctrl + Shift + P

コマンドパレット

Ctrl + P

ファイルを素早く開く

F1

ヘルプを検索

Ctrl + F1 ～ Ctrl + F5

メイン画面を「2D」「3D」「スクリプト」「ゲーム」「AssetLib」に切り替える。
