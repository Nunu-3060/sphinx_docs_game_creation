第 3 章　環境構築

本章では、Godot を入手して起動し、最初のプロジェクトを作って「Hello, Godot!」と表示するまでを説明する。最後に、外部のコードエディターと連携する方法を紹介する。

Godot の入手

Godot は公式サイトの ダウンロードページ から入手できる。Windows 向けには次の 2 種類がある。

表 8 Godot の配布版

種類

説明

標準版（Standard）

GDScript でゲームを作るための版。本書はこちらを使う。

.NET 版

標準版の機能に加えて、C# でスクリプトを書ける版。別途 .NET SDK のインストールが必要になる。

ダウンロードした zip ファイルを展開すると、次の 2 つの実行ファイルが入っている。

表 9 展開されるファイル

ファイル名

説明

Godot_v4.7.2-stable_win64.exe

エディター本体。通常はこちらを起動する。

Godot_v4.7.2-stable_win64_console.exe

コンソール付きで起動するための補助ファイル。エディターと一緒にコマンドプロンプトの画面が開き、ログやエラーがそこにも表示される。エディターが起動しない場合の原因調査や、コマンドラインからの実行に使う。

Godot にはインストーラーがない。2 つのファイルを同じフォルダーに置き、好きな場所（例えば C:\Tools\Godot）に保存すればよい。必要に応じて、デスクトップやスタートメニューにショートカットを作っておく。

注釈

エディターの設定は、既定では %APPDATA%\Godot フォルダーに保存される。実行ファイルと同じフォルダーに _sc_ という名前の空のファイルを置くと、設定を実行ファイルと同じフォルダー内に保存する「自己完結モード」になる。USB メモリーなどに入れて持ち運ぶ場合に便利である。

プロジェクトマネージャー

Godot_v4.7.2-stable_win64.exe を起動すると、プロジェクトマネージャーが表示される。プロジェクトマネージャーは、作成済みのプロジェクトの一覧を表示し、プロジェクトの作成、インポート、削除を行う画面である。

Godot のプロジェクトは、project.godot という設定ファイルを含む 1 つのフォルダーである。シーン、スクリプト、画像などのファイルは、すべてこのフォルダーの中に置く。

新しいプロジェクトを作る

プロジェクトマネージャーで「新規プロジェクト」（New Project）を押すと、「新規プロジェクトを作成」ダイアログが開く。次の項目を設定する。

レンダラーの選び方

レンダラーは、画面を描画する方式である。Godot 4 には次の 3 種類がある。

表 11 レンダラーの種類

レンダラー

特徴

向いている用途

Forward+

Vulkan、Direct3D 12、Metal を使う。最も高機能で、高度な 3D の表現ができる。

デスクトップ PC 向けの 3D ゲーム

モバイル（Mobile）

Forward+ より機能を絞り、モバイル端末の GPU でも速く動くようにしたもの。

スマートフォン向けの 3D ゲーム

互換性（Compatibility）

OpenGL 3.3、OpenGL ES 3.0、WebGL 2.0 を使う。古い PC やブラウザーでも動く。3D の高度な機能の一部は使えない。

2D ゲーム、Web ブラウザー向けのゲーム、性能の低い PC

本書では 2D ゲームを主に扱い、Web ブラウザー向けの書き出しも紹介するので、互換性レンダラーを使う。2D の機能は、どのレンダラーでもほぼ同じように使える。レンダラーは、後から「プロジェクト」→「プロジェクト設定」の「レンダリング」→「レンダラー」で変更できる。

既存のプロジェクトを開く

本書のサンプルプロジェクトのように、すでにあるプロジェクトを開くには、プロジェクトマネージャーの「インポート」（Import）を押し、プロジェクトのフォルダー内にある project.godot を選ぶ。一度インポートしたプロジェクトは一覧に表示され、ダブルクリックで開けるようになる。

エディターの表示言語

Godot エディターの表示言語は、既定では OS の言語に合わせて自動で決まる。英語の情報（公式ドキュメントや海外の解説記事）と照らし合わせながら学ぶ場合は、英語表示のほうが便利なこともある。表示言語は「エディター」→「エディター設定」の「インターフェース」→「エディター」にある「エディターの言語」で変更できる。変更はエディターの再起動後に反映される。

また、インスペクターに表示されるプロパティ名は、既定ではエディターの言語に翻訳される。同じ画面の「インターフェース」→「インスペクター」にある「デフォルトのプロパティ名のスタイル」を「Raw」にすると、スクリプトで使う名前（position など）がそのまま表示される。本書は既定の日本語表示を前提とし、スクリプトで使う名前を括弧内に添える。

Hello, Godot!

作成したプロジェクトで、画面に文字を表示する最初のゲームを作る。完成したものはサンプルプロジェクトの chapter03/hello.tscn にある。

  1. シーンを作る：エディター左上の「シーン」ドックに「ルートノードを生成:」という欄がある。「2D シーン」を押すと、Node2D という種類のノードが 1 つだけあるシーンができる。

  2. 名前を変える：作られた Node2D をダブルクリックし、名前を Hello に変える。

  3. 子ノードを追加する：Hello を選んだ状態で Ctrl + A を押すと、「新規ノードを作成」ダイアログが開く。検索欄に Label と入力して Label を選び、「作成」を押す。追加したノードの名前を Message に変える。

  4. 文字の大きさを変える：Message を選ぶと、右側のインスペクターにプロパティが表示される。「テーマのオーバーライド」→「フォントサイズ」の「フォントサイズ」にチェックを入れ、40 にする。

  5. シーンを保存する：Ctrl + S を押し、hello.tscn という名前で保存する。

  6. スクリプトを付ける：Hello ノードを右クリックし、「スクリプトをアタッチ」を選ぶ。ダイアログの設定は既定のまま「作成」を押すと、hello.gd が作られてスクリプトエディターが開く。

  7. コードを書く：スクリプトの内容を次のように書き換え、Ctrl + S で保存する。

リスト 1 chapter03/hello.gd
1extends Node2D
2## 最初のスクリプト。起動時にメッセージを出力し、ラベルの文字を書き換える。
3
4
5func _ready() -> void:
6    print("Hello, Godot!")
7    $Message.text = "Hello, Godot!"

1 行目の extends Node2D は、このスクリプトが Node2D ノードに付けるものであることを表す。## `` で始まる行はドキュメントコメントで、エディターのヘルプに表示される。``_ready() は、ノードの準備ができたときに Godot が 1 回だけ呼び出す関数である。print() は「出力」パネルに文字を表示し、$Message は子ノードの Message を取得する書き方である。これらは 第 5 章　ノードとシーン と 第 6 章　GDScript の基礎 で詳しく説明する。

最後に F6（現在のシーンを実行）を押す。ゲームのウィンドウが開いて「Hello, Godot!」と表示され、エディター下部の「出力」パネルにも同じ文字が出力されれば成功である。ウィンドウを閉じるか F8 を押すと、実行が止まる。

Tip

F5（プロジェクトを実行）を押すと、プロジェクトの「メインシーン」が実行される。メインシーンが決まっていない場合は、どのシーンをメインにするかを尋ねるダイアログが表示される。「現在のものを選択」を押すと、今開いているシーンがメインシーンになる。

ゲームウィンドウの埋め込み

Windows 版のエディターでは、実行したゲームの画面を、エディター上部の「ゲーム」画面（Ctrl + F4）の中に埋め込んで表示できる。埋め込むか別ウィンドウで表示するかは、「ゲーム」画面のツールバーのメニューにある「次の実行時にゲームを埋め込む」で切り替える。どちらの表示方法でも、ゲームの動作は変わらない。

外部のコードエディターを使う

Godot には GDScript の補完やエラー表示に対応したスクリプトエディターが内蔵されているので、本書の範囲ではそれで十分である。普段から Visual Studio Code（以下、VS Code）を使っている場合は、VS Code でスクリプトを編集することもできる。

  1. VS Code に、GDScript 用の拡張機能「godot-tools」をインストールする。

  2. Godot の「エディター」→「エディター設定」を開き、「テキストエディター」→「外部」で次のように設定する。

    表 12 外部エディターの設定

    項目

    設定値

    外部エディターを使用

    オン

    実行パス

    VS Code の実行ファイル（Code.exe）のパス

    実行フラグ

    {project} --goto {file}:{line}:{col}

  3. Godot のエディターを開いたまま、VS Code でプロジェクトのフォルダーを開く。

godot-tools は、起動中の Godot エディターが提供する言語サーバー（既定のポート番号は 6005）に接続して、補完や定義へのジャンプを実現する。そのため、VS Code で編集するときも Godot のエディターは起動しておく必要がある。
